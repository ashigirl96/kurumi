# `resume` の失敗ははっきり知らせ、自動で文脈を組み直さない

`resume` の前に、ホストが SDK の出力から記録したターンごとの id が会話記録に残っているかを照合し、合わなければ会話の記録を読めなかったと利用者に知らせて、新しいセッションを始めるかを利用者に任せる。会話記録が存在しない場合や中身がすべて壊れている場合ははっきり失敗するが、利用者の発言の行が壊れている場合は成功扱いのまま空の会話から始まった（実測）。DB から文脈を組み直すとツールの結果が欠けるうえ失敗を隠すので、自動の組み直しは持たない。

照合で見つけられるのは、事故による壊れだけである。エージェントによる書き換えは見つけられない（ADR-0004）。
