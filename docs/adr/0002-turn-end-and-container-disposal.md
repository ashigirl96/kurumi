# ターンは押し込んだ受信メッセージをすべて片付けてから終え、その直後にコンテナを捨てる

Turn（ターン）は、最新の `result` が届き、ターンの途中で押し込んだ Inbound Message（受信メッセージ）がすべて `command_lifecycle` で completed か cancelled になり、Approval Request（承認依頼）が残っていない時点で終える。終えると決めたら、それ以降に届いた受信メッセージは押し込まずに次のターンへ回し、`close()` の後に `docker rm -f` でコンテナを捨てる。最後のツール呼び出しの後に押し込んだメッセージは、同じ `query` の中で別の CLI ターンとして答えられるので（9 回中 9 回、実測）、最初の `result` で閉じるとそのメッセージを落とす。

受信メッセージについて DB に持つのは、受信したこと、どのターンに渡したか、答え終えたかの 3 つだけにする。モデルが読んだかどうかはターンの最中に `command_lifecycle` で見る。

確認の範囲: `result` の約 150 ms 後に捨てても会話記録は書き切られており、次のターンで続きを覚えていた（3 回中 3 回、Docker Desktop for Mac で実測）。
