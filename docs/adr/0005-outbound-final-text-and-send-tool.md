# 最後の文はホストが届け、送るツールは途中経過に使う

各 CLI ターンの `result` の文はホストが Outbound Message（送信メッセージ）として届け、エージェントの送るツールはターン途中の経過を知らせるために使う。送るツールだけが届く形では、エージェントが答えを最後の文にだけ書き、利用者に何も届かないことがあった（haiku で 5 回中 4 回、実測）。送信は `pending`、`sending`、`delivered` と進め、起動時に `sending` で残っている行は送り直す（少なくとも 1 回届ける）。送るツールの呼び出しには、ツール呼び出しの id を一意のキーとして付ける。

## Consequences

- 同じツール呼び出しを CLI が再実行したことは 36 回中 1 度もなかったので、id による重複除去は補助の守りである。中断後の送り直しは、ADR-0004 の中断の知らせで防ぐ。
- 長い作業で、途中経過と最後の文が重複するかは測っていない。
