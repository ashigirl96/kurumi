# Triage のラベル

skill は triage を 5 つの役割で語る。このファイルは、その役割をこの repo の issue tracker で使う実際のラベル名に対応させる。

| mattpocock/skills でのラベル | この repo でのラベル | 意味                                       |
| ---------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`               | `needs-triage`       | メンテナが内容を見て判断する必要がある     |
| `needs-info`                 | `needs-info`         | 報告者からの追加の情報を待っている         |
| `ready-for-agent`            | `ready-for-agent`    | 仕様が固まり、人の付かない agent に任せられる |
| `ready-for-human`            | `ready-for-human`    | 人が実装する必要がある                     |
| `wontfix`                    | `wontfix`            | 対応しない                                 |

skill が役割を名指ししたら（例:「agent に任せられる triage ラベルを付ける」）、この表の対応するラベル名を使う。

実際に使っている名前に合わせたいときは「この repo でのラベル」の列を書き換える。
